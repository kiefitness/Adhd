4:5 成人 ADHD 學習圖文
認知心理學指南

成人 ADHD 並非「完全無法專注」
而是「專注力調節機制障礙」

核心認知觀念
大腦並非缺乏專注的能量，而是缺少穩定將注意力「指派與定速」於特定任務的控制開關。
ADHD Learning Profile 01 / 07
學習特質 01

1. 極端的專注力模式：
拖延與超專注 (Hyperfocus) 並存

困難啟動 (Task Initiation)
面對不感興趣、結構複雜或需長期投入的任務時，大腦難以分泌足夠多巴胺啟動行為，常陷入嚴重拖延。
超專注狀態 (Hyperfocus)
一旦遇到極度感興趣的課題，或面臨 Deadline 的極大威脅時，大腦能在短時間內展現驚人的爆發力與吸收效率。
Focus Regulation 02 / 07
學習特質 02

2. 工作記憶障礙
(Working Memory Deficits)

閱讀效率低：無法整合前文
閱讀長篇文章或教科書時，難以暫存資訊，常出現「字看得進去，卻沒讀進腦袋」，需要重複閱讀同一段落。
容易遺忘關鍵指令
聽講或閱讀時，若缺乏視覺化筆記輔助，極易遺漏多步驟的 instructions 或公式細節。
Working Memory 03 / 07
學習特質 03

3. 組織規劃與時間感缺失
(Time Blindness)

時間感知失真
難以準確預估完成一項研讀任務或作業所需的時間，導致原本安排的學習時程表形同虛設。
三分鐘熱度 (Lack of Follow-Through)
剛接觸新領域時充滿熱情（購買大量書籍或課程），但當新鮮感消退、進入枯燥複習階段時，極難維持動力。
Time Planning 04 / 07
學習特質 04

4. 思維飄忽與高昂精神消耗
(Ceaseless Mental Noise)

腦中無休止的背景雜音
靜心讀書時，腦中會持續浮現無關的雜念 (Wandering Mind)。為了將注意力拉回課本，需要耗費龐大的意志力與心理能量。
極易產生身心疲憊感
這並非意志力薄弱，而是大腦背景過濾機制需要額外高強度運轉所帶來的生理疲勞。
Internal Noise 05 / 07
學習特質 05

5. 潛在的學習優勢
(Potential Strengths)

若能找到感興趣的領域或適合的工具，ADHD 成人常展現出：

發散性思維

Divergent Thinking 跳躍想像

跨領域連結

優異的概念組合能力

創新解題

突破傳統框架的視角

高度創造力

感興趣領域展現極致原創

行動指南

理解 ADHD 大腦：
重塑適合自己的學習動線

視覺化外掛：心智圖與顏色圖卡替代純文字筆記。
微型啟動：設定「只讀 5 分鐘」，降低多巴胺門檻。
具象化時間：使用沙漏或計時器建立實體時間感。

「並非專注力不夠，而是需要對的啟動鑰匙。」
